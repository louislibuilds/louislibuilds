## 关于我

Helluu，我是 bubblechickenlab。:)

我是全栈开发者，悉尼科技大学（UTS）信息技术硕士毕业（WAM 86.9 · Dean's List）。在 [bubblechickenlab.com](https://www.bubblechickenlab.com) 独立交付正式上线的 Web 应用 — 从数据库 schema、auth 到部署全程负责。

我的工作介于工程与叙事之间：作品集即建筑、互动式简历、以及源自真实求职流程的工具。平台 UI 支持四语（英 · 繁中 · 简中 · 日本語）。

不写代码的时候，我大概在打游戏、健身、做饭，或者计划下一趟旅行。
